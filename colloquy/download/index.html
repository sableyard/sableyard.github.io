Install in four steps

  1. Download the APK on your Android phone.
  2. Open the file. If Android asks, allow your browser or file manager to install apps (Settings → Install unknown apps).
  3. Tap Install. Android may warn you because Colloquy is a new app outside the Play Store. Choose to install anyway if you trust the source.
  4. Open Colloquy, add an API key from a provider you use, and start chatting.

Verify your download (optional)

Each release lists a SHA-256 checksum above. After downloading, compare it with your file to be sure nothing changed on the way.

# Windows (PowerShell)
Get-FileHash colloquy.apk -Algorithm SHA256

# macOS / Linux
shasum -a 256 colloquy.apk

Good to know

  • Updates are manual for now: download the newest APK and install it over the old one. Your chats and keys stay.
  • Colloquy needs no account. Your keys and chats stay on your phone.
  • You can turn “install unknown apps” off again after installing.
