Changelog

What changed in each version of Colloquy.

0.1.0

First public build
  • Chat with OpenAI, Anthropic, Google Gemini, xAI, Mistral, Groq, DeepSeek, Perplexity, OpenRouter and custom compatible endpoints.
  • Your own API keys, encrypted with the Android Keystore. No account, no ads, no analytics.
  • Streaming replies, switching models mid-chat, and web search where the model supports it.
  • Voice dictation, read-aloud, and photo and file attachments.
  • Chat history with search, pin, rename and archive; export to Markdown, text or JSON; import from JSON.
  • Light, dark and system themes.

Known limits: math formulas show as plain text for now.
