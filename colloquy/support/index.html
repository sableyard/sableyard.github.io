Support

Something not working? Start with the answers below, or email us.

support.sableyard@gmail.com

Please include your Android version, the Colloquy version, and what you did. Never send your API key.

My API key doesn't work

Check that the key belongs to the provider you selected, that it has no extra spaces, and that the account has credit or billing enabled where the provider requires it. In Settings → Providers, remove the key and add it again.

Messages fail with a network error

Check your internet connection and try another model. Provider outages, VPNs and firewalls can also block requests.

Voice input stops or doesn't start

Allow the microphone permission. Speech recognition is provided by your phone's speech service, so make sure it is installed and up to date.

The app won't install

Allow installs from your browser or file manager (Settings → Install unknown apps), make sure your phone runs Android 8.0 or newer, and check that you have free storage.

How do I delete my data?

Delete single chats from the chat list, or use Settings → Data & Privacy → Delete all local data. Uninstalling the app also removes its data. Data already sent to an AI provider must be deleted through that provider.

Where are my chats stored?

Only on your phone, in the app's private storage.
